Moxie portal snippets: configuration tool

None of this is a documented Moxie API, so a portal update can rename an element, a component or an endpoint and break a snippet. The whole thing might just stop working. Don't use this approach for anything mission-critical that must run, because the day might come when it just stops doing anything.

Your script

  1. Copy the script above (or download it and open the file).
  2. In Moxie, open Settings > Client Portal > Advanced and find the JavaScript embed code box.
  3. Paste the script into that box, replacing anything already there, and save.

Moxie portal snippets: configuration tool

None of this is a documented Moxie API, so a portal update can rename an element, a component or an endpoint and break a snippet. The whole thing might just stop working. The snippets and their instructions are in the snippets repository on GitHub.

Your script

  1. Copy the script above (or download it and open the file).
  2. In Moxie, open Settings > Client Portal > Advanced and find the JavaScript embed code box.
  3. Paste the script into that box, replacing anything already there, and save.
  4. Check your work by viewing the portal as a client. Load it sparingly: Moxie's sign-in service blocks an address that loads the portal roughly fifteen times in five minutes.
